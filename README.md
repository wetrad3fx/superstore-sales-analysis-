# Superstore Sales Analysis

Project Overview

This project presents an Excel-based analysis of Superstore sales data. The analysis explores sales performance, customer segments, product categories, regions, and other key business metrics.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Visualization

## Objectives

The main objectives of this project are to:

- Analyze overall sales performance
- Identify top-performing product categories and sub-categories
- Analyze sales by region and state
- Understand customer segment performance
- Identify trends and business opportunities
- Build an interactive Excel dashboard

## Key Analysis

The project includes analysis of:

- Sales
- Orders
- Customers
- Products
- Categories
- Sub-Categories
- Regions
- States
- Customer Segments
- Shipping

## Dashboard

An interactive Excel dashboard was developed to provide a clear overview of the company's sales performance.
